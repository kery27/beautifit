# beautifit — 헤어 미러

정면 사진 한 장(또는 실시간 카메라)에 **실제 가발 사진**을 씌워 보고,
**변신** 버튼으로 AI가 한 번 더 자연스럽게 합성해 주는 미용실 상담용 모바일 웹앱이에요.

- 바로 쓰기: <https://kery27.github.io/beautifit/> (GitHub Pages를 켠 뒤)
- 휴대폰에 맞춰 만들었어요. 사진 위에 떠 있는 편집판에서 스타일·컬러·위치·비교를 바로 바꾸고, 결과가 즉시 보여요.

## 기능

| 기능 | 내용 |
|---|---|
| 실사 가발 6종 | 내추럴 레이어드, 비치 웨이브 단발, 슬릭 롱 스트레이트, 커튼뱅 롱헤어, 컬리 단발, 볼륨 웨이브 롱헤어 |
| 자동 맞춤 | 얼굴 인식(MediaPipe Face Mesh, 478개 지점)으로 이마 꼭대기·얼굴 폭에 맞춰 가발을 붙여요 |
| 컬러 | 원본 색 + 8색. 사진의 윤기·결은 그대로 두고 색만 바꿔요 |
| 위치 | 크기·폭·높이 조절, **사진만 움직이기**(헤어는 고정하고 뒤의 사진만 끌기·두 손가락으로 크기) |
| 화면 | 확대·축소·이동, 사진 밖으로 나간 머리도 잘리지 않게 배경을 넓혀요 |
| 변신 (AI) | 지금 화면을 AI가 다시 합성해 머리선·그림자·조명을 자연스럽게. 시도할 때마다 토큰 1개 차감, 10개 한도 |
| 저장 | 3:4 세로 사진으로 저장 (휴대폰은 공유 창 → 사진에 저장) |

사진은 기기 안에서만 처리돼요. **변신**을 누를 때만 그 화면 한 장이 AI 서버로 보내져요.

## 변신: 체험 모드와 진짜 AI

- `config.js` 의 `aiUrl` 이 비어 있으면 **체험 모드**예요. 기기 안에서 경계·조명을 간단히 다듬고, 토큰 차감·10개 한도는 실제와 똑같이 동작해요. 토큰은 이 브라우저에 저장돼요.
- 진짜 AI 합성은 `server/` 의 Cloudflare Worker를 올리고 `config.js` 의 `aiUrl` 에 그 주소를 넣으면 돼요(빌드 필요 없음). 서버가 Gemini 이미지 편집 모델을 부르고, 기기별 토큰과 하루 상한도 서버가 직접 세요. 순서는 [server/README.md](server/README.md) 에 있어요.

## 폴더

```
index.html        앱 (빌드 결과 — GitHub Pages가 이 파일을 보여줌)
config.js         설정 — AI 변신 서버 주소(aiUrl)
src/app.src.html  앱 원본 (화면·편집·변신·토큰·저장)
src/wig.js        가발 엔진 (가발 사진 배치·색 바꾸기)
build.py          src → index.html 빌드
mp/               얼굴 인식 엔진 파일 (MediaPipe Face Mesh)
wigs/             실사 가발 이미지 (체크무늬 배경을 걷어내고 오려낸 것)
server/           AI 변신 서버 (Cloudflare Worker)
```

`src/` 를 고친 뒤 `python3 build.py` 를 실행하고 `index.html` 을 함께 커밋하면 돼요.

## 가발 추가하기

`wigs/` 에 투명 배경 가발 이미지를 넣고, `src/wig.js` 의 `PH` 목록에 한 줄을 추가해요.

```js
이름:{name:'표시 이름',f:'wigs/파일.webp',cx:이마점X,cy:이마점Y,w:얼굴폭}
```

- 숫자는 모두 이미지 픽셀 기준이에요.
- `cx`, `cy` 는 얼굴 구멍 가운데 이마 꼭대기 자리예요.
- `w` 는 그 가발에 맞는 얼굴 폭이에요. 보통 얼굴 구멍의 가장 넓은 폭의 약 1.05배예요.
